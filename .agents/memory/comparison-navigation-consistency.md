description: Coaches need identical comparison-mode navigation in Ticketing and GameDay.

Keep comparison tabs identical in Ticketing and GameDay: use the same names, order, and visual treatment. Use the established Ticketing navigation as the reference when extending GameDay.

**Why:** The user explicitly said identical tabs are easier for coaches to understand and use. Separate terminology for equivalent comparison modes creates avoidable confusion.

**How to apply:** When adding or changing comparison navigation, make the same change in both modules. Differences in their financial metrics do not justify different names or ordering for the shared comparison modes.
