---
name: Comparison crests
description: Visual accuracy and print reliability constraints for comparison badges in the app and PDF.
---

Use the same verified, locally served crests in the comparison app and PDFs. Show a rival crest only when it matches a specific opponent represented by the comparison; a multi-opponent summary must not be branded as one rival. Match competition badges to the actual competition, and retain readable text if a verified image is unavailable.

**Why:** Public image searches returned football clubs, unrelated teams, historical variants, and even generic placeholders for some basketball rivals; externally hosted images also may fail or print before loading. A plausible but wrong crest is worse than an explicit text label.

**How to apply:** Verify image content visually before adding a new mapping, use shared logo resolution in the app and PDF so they stay in sync, and wait for images to load before invoking print.

For university-affiliated opponents, a university mark is suitable only when the institution's official basketball-team page itself uses it. The TSU basketball-team page at https://www.tsu.ge/en/sport-and-culture/page/Basketball-Team-TSU uses the university seal; this was cross-checked against a basketball team listing rather than inferred from the institution name alone.

**Why:** A school's institutional seal is not automatically the basketball club's crest.

**How to apply:** Check the official team's own page before using a shared institution mark in a rival report.
